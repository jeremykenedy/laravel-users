## Reading early versions

The v0.0.3rc and v0.0.2 tags point to the same commit. The v0.9.0 tag points to a commit newer than those used by v1.0.0 and v1.0.1. The canonical entries explain these cases and link their source comparisons; version order alone is not a reliable timeline for these early tags.

The [GitHub releases](https://github.com/jeremykenedy/laravel-users/releases) and [tag list](https://github.com/jeremykenedy/laravel-users/tags) preserve the original tag spelling, including uppercase `V4.4.0` and `V5.0.0`.
